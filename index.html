Online vision · modlens v2

One tool. Your app model. Structured sight.

vision_cloud_tool reads images through a model you already configured in DeepSeek Harness, and returns modlens v2 evidence — summary, transcription, layout, semantics, visual clues, uncertainty. No Python, no local tools, no extra key.

Install GitHub

Simpler by design.

The original bundle shipped ten tools and a Python runtime. This version keeps only what an online vision bridge needs.

One tool

vision_cloud_tool covers describe, question, OCR, re-analyze, and multi-image comparison.

App model

URL, model, and key come from the DSH provider registry. The plugin holds no credential.

modlens v2 output

Six required evidence fields, no fabricated pixel boxes or confidence.

Install into a profile.

Requires DeepSeek Harness and Node.js 22.19+ or 24. After restarting a Web profile, open Settings → Vision, pick a model, and save.

dsh plugin --profile web add dsh-vision-cloud
dsh plugin --profile headless add dsh-vision-cloud

dsh --profile web --dump-config | grep vision-cloud
